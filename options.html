Vibe Check for X

Your draft and reply/quote context are sent to TypeSafe's Jev model with the rubrics below. If media description is enabled and an OpenAI key is configured, images/video frames are sent to OpenAI and their descriptions to Jev. Settings and API keys are stored in your browser's extension sync storage.

Get one at console.typesafe.ai. Stored in your browser's extension sync storage; only used from the extension's background.

Images & video

Jev is text-only. With an OpenAI key, attached images (and the first frame of videos/GIFs) are described by a vision model and the description is passed to Jev as media. Images on the tweet you're replying to are described too.

Any OpenAI chat model that accepts image input. Defaults to gpt-4o-mini. Change this if you want a different model (e.g. one your account has special access to).

Behavior

Every analysis costs tokens (roughly the length of your draft plus the rubrics, ~1.5k tokens). Media descriptions are cached per attachment, so they're only paid for once. Turn auto off and use the Check button or ⌘⇧V if you want full control.
Array of { id, label, type, instructions, criteria, polarity, weight }. type is score (ordered levels, low→high), noul (yes/no probability) or choice (one of a set). polarity good/bad and weight drive the overall verdict; neutral or weight 0 means display only. "requires": "media" asks the question only when media is attached. Reference the draft as `draft`, attached media descriptions as `media`, the tweet being replied to as `reply_to`, and a quoted tweet as `quoting`.
